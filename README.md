This is a school project using nntp protocol

I have used these nntp documentations for the project:
https://www.rfc-editor.org/info/rfc3977/ 
https://www.w3.org/Protocols/rfc977/rfc977
https://www.rfc-editor.org/info/rfc6048/

Its a Nntp news reader:
The reader uses Tcpclient to connect to the server

Missing features:
Currently it is only setup to run on:
Host: reader80.eternal-september.org
Port: 80
Still missing manual input of server and host

Currently you can not save your login on you computer

You can not add NewsGroups as favorite

You can not download from the server
